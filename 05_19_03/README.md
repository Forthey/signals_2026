# Идея доказательства

Пусть C - бинарный код Хэмминга с проверочной матрицей

$$ H \in F_2 ^{m*(2^m-1)} $$

Тогда:

- Длина кода $ n = 2^m - 1 $
- $ rank(H) = m $
- Параметры кода Хэмминга $ C = [2^m - 1, 2^m - 1 - m, 3] $
- $ C^⊥ = Row(H) $
- $ dim C^⊥ = m $

**Идея - доказать, что все ненулевые веса кодовых слов $ C^⊥ $ равны $ n = 2^m - 1 $**
